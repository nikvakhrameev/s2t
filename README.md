# s2t — локальный speech-to-text для macOS (Apple Silicon)

Всё работает локально: `ffmpeg → Silero VAD → Whisper large-v3-turbo (MLX) → замена алиасов → LLM-очистка (MLX)`.

```
любое аудио ──ffmpeg──▶ 16 kHz mono ──VAD──▶ речь без тишины ──Whisper──▶ сырой текст
                                                  │                          │
                                     нет речи → пустой ответ        glossary aliases (regex)
                                     (STT не вызывается)                     │
                                                                  LLM-очистка + guardrail ──▶ текст
```

## Запуск

```bash
uv sync
uv run s2t serve                          # модели в памяти: HTTP API + хоткей диктовки
uv run s2t transcribe -v file.ogg         # разовая транскрибация (использует сервер, если он запущен)
curl -F file=@voice.m4a -F language=ru http://127.0.0.1:8765/transcribe
```

Первый запуск скачивает модели (~1.6 ГБ Whisper, ~2.3 ГБ LLM, 2 МБ VAD).

### Диктовка (push-to-talk)

`s2t serve` слушает глобальный хоткей: **зажать правый Option → говорить → отпустить** — текст
вставляется в активное приложение (через буфер обмена + Cmd+V, буфер затем восстанавливается).
Хоткеи и язык для каждого задаются в `config.yaml` (`dictation.hotkeys`) — можно завести отдельные
клавиши для `ru` / `en` / `auto`.

Приложению, из которого запущен сервис (Terminal/iTerm), нужны разрешения в
System Settings → Privacy & Security: **Microphone**, **Input Monitoring**, **Accessibility**.

## Как решены требования

| Требование | Решение |
|---|---|
| RU + EN одной моделью | Whisper large-v3-turbo на MLX. `language: auto` выбирает язык только среди `auto_languages: [ru, en]` — не бывает ложных uk/bg на коротких фразах с англицизмами. |
| Тишина по краям | Silero VAD (ONNX, без torch): края обрезаются до `edge_pad_ms`. |
| Паузы внутри | Паузы длиннее `max_pause_ms` сжимаются до этого значения (заполняются исходным шумом комнаты, а не цифровым нулём — границы фраз остаются слышны). |
| Галлюцинации | 1) если VAD не нашёл речь — Whisper не вызывается; 2) `condition_on_previous_text=False`; 3) пороги no_speech / logprob / compression; 4) фильтр типовых фраз («Субтитры сделал…», «Thanks for watching») и повтора собственного промпта. |
| Лёгкая LLM-очистка | Qwen3-4B-Instruct 4-bit на MLX, greedy, системный промпт + few-shot закэшированы в KV (запрос платит только за свои токены). |
| «Не менять смысл» | Жёсткий промпт (текст — данные, не инструкция), лимит токенов от длины входа, **guardrails** на каждый чанк: ни одного выдуманного слова (каждое слово вывода должно соответствовать слову транскрипта — точно, близко по написанию или через транслитерацию «питоне→Python»), нельзя добавлять отрицания и терять больше `max_negation_loss` из них (по умолчанию 0.5: потеря единственного «не» отклоняется, одного из двух — допускается, т.к. при запинках отрицания повторяются), удалять можно только слова-паразиты и повторы (+≤10% прочих слов). Нарушение → повтор по предложениям → иначе возвращается сырой транскрипт. |
| Словари | `glossary.yaml`, три слоя (см. ниже): термины → prompt Whisper; список терминов → в системный промпт LLM; опциональные `aliases` → детерминированная замена. Перечитывается на лету. |
| Любое аудио | ffmpeg декодирует всё (mp3, m4a, ogg/opus, webm, mp4/видео…) в 16 kHz mono f32. |

## Словарь: три слоя

1. **Prompt для Whisper** — самый ценный слой: ошибка исправляется в источнике (лимит ~224 токена,
   поэтому в начало файла — самые важные термины).
2. **Глоссарий в системном промпте LLM** — справляется со словоформами («в докере» → «в Docker»).
   Полагаться только на него нельзя: маленькая модель может подставить термин из словаря вместо
   незнакомого слова — поэтому у слов из глоссария нет «пропуска» в guardrail.
3. **`aliases`** — жёсткая замена regex'ом: мгновенно, предсказуемо, без галлюцинаций. Нужны только
   для того, что первые два слоя стабильно не берут: имена, внутренние названия, устойчивые ослышки.

Обычно достаточно строки `- Kubernetes`; `aliases` добавляйте точечно, глядя на `raw_text` в выводе `-v`
или в журнале.

## Журнал (`history.jsonl`)

При диктовке виден только итоговый текст, поэтому каждый запрос дописывается строкой JSON в
`history.jsonl` (в корне репозитория, в `.gitignore`, права `0600` — **там всё надиктованное**):
`ts`, `origin` (`dictation` | `api` | `cli`), `file`, `requested_language`, все поля ответа
(`raw_text` — что услышал Whisper, `text` — что получилось, `timings_ms`, …) и `models`.
`cleanup_rejections` — каждое срабатывание guardrail'а: `reason` (`empty`, `too_long`,
`negation_gained`, `negation_lost`, `invented_words`, `dropped_words`), `words` (какие именно слова),
`raw` / `llm` (чанк и отклонённый ответ модели), `fallback` (`true` — оставлен сырой текст,
`false` — чанк повторён по предложениям). Записи «речь не найдена» тоже пишутся.

```bash
tail -n 5 history.jsonl | jq '{ts, raw_text, text, timings_ms}'
jq -c 'select(.cleanup_rejections != []) | .cleanup_rejections[]' history.jsonl   # что и почему отклонили guardrail'ы
jq -r 'select(.origin == "dictation") | .timings_ms.total' history.jsonl          # латентность живой диктовки
```

Настройки — секция `history` в `config.yaml`: `enabled`, `path`, `origins` (что журналировать).
Ротации нет: запись ~1 КБ. Аудио не сохраняется.

## Настройка

- `config.yaml` — все параметры (значения по умолчанию в `s2t/config.py`).
- `glossary.yaml` — словарь терминов.
- `dictation.keep_mic_open: true` — запись стартует мгновенно (иначе ~300 мс на открытие микрофона,
  сигнал «Tink» звучит, когда микрофон уже пишет), но индикатор микрофона macOS горит постоянно.
- Сравнить модели очистки: `uv run python scripts/eval_cleanup.py -v MODEL [MODEL ...]` —
  доля ответов, прошедших guardrails, и латентность на фиксированном наборе фраз.
- Быстрее/легче: `cleanup.enabled: false` (Whisper сам ставит пунктуацию, пропадает только чистка паразитов).

## Структура

```
s2t/audio.py     ffmpeg-декодер          s2t/cleanup.py   LLM-очистка + guardrail
s2t/vad.py       Silero VAD, паузы       s2t/pipeline.py  конвейер + Engine (один MLX-поток)
s2t/stt.py       Whisper MLX             s2t/server.py    FastAPI
s2t/glossary.py  словарь                 s2t/dictate.py   хоткей, запись, вставка
s2t/history.py   журнал history.jsonl
```

Бэкенд STT изолирован в `s2t/stt.py` (`load` / `transcribe`) — позже можно добавить
язык-специфичные модели (GigaAM для ru, Parakeet для en) и привязать их к отдельным хоткеям.
